## Goal

Make a finished report answer “what changed with policies?” before showing its component scores.

## Scope

- Rebuild the report hierarchy from `design/red-team/v3/report.html`. Put raw then protected rates and their signed percentage-point delta first when a same-suite match exists; otherwise say “No paired result for this suite.” A zero delta is a number, never “Not scored.”
- From the shared DTO (spec 07) consume `risk`, `attack_success`, `decided`, `threshold`, `engine`, `paired`, `trend` and `provisional`. Do not recompute backend scoring. None-level risk displays zero; missing risk displays “Not scored”; provisional scores must not look final.
- For recorded promptfoo provenance show “Generated by promptfoo 0.126.0 · N attacks · graded by <model>”, substituting actual version/count and omitting unknown provenance. Plugin and strategy rows show decided coverage and outcome counts; no controls-column legacy branch.
- Use existing tokens only, no raw colour values. Caption or label tables; keep scroll regions focusable and visibly outlined; don't hide a value in color or hover. Use no animated metrics or decorative motion; honor reduced motion. Use specific coverage copy, no generic filler.

## Explicit non-scope

- Backend normalization and risk calculations → spec 06.
- Compliance and drill-down → spec 14 and spec 15.
- Page composition → spec 18.

## Reuse first

- Adapt the three incumbent components and semantic table primitives. Follow `DESIGN-SYSTEM.md#colour-tokens`, `#layout-conventions`, `#states-and-motion` and `#accessibility-floor`.
- Use report fixtures based on `ARCHITECTURE.md` and spec 07 while spec 06 is built separately; report-score semantics are researched in `docs/research/promptfoo-redteam.md` §8.

## Steps

1. Map DTO values onto accessible summary and the paired-first layout.
2. Update the plugin and strategy tables with populated and zero-denominator fixtures, keyed by stable IDs.
3. Test coverage, provenance, provisional versus final, and signed delta without testing CSS pixels.
