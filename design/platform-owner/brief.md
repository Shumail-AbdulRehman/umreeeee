# Averiq Platform design brief

Averiq's product owner opens this workspace to find customer companies that need attention, see the evidence behind each issue, and manage access. The mode is Operate. The four defining screens are Platform overview, Companies, Company detail and Audit log. A company detail includes the preview of a reversible access change.

Use Averiq's light canvas, graphite navigation, Inter typography and restrained violet accent as fixed inputs. The layout uses a split heading and date control, a four-column metric strip, a two-column investigation area and a full-width comparison table. Composition follows the operator's sequence from portfolio to issue to company action. The heading fits on one line on desktop and has room to wrap on narrow screens. The two investigation columns fill their row. Hold charts and rows still during reading and comparison.

Use self-contained HTML, CSS and JavaScript for review. The eventual implementation uses the existing React and Tailwind component system. All records in the prototype are sample data. Preserve clear distinctions among access, onboarding and actual workspace use. Keep company-level metadata in the platform view.
