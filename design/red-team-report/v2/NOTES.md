# v2 motion

The animate pass keeps charts, scores and tables stable for reading. The only motion signals a pointer interaction.

| Element | Trigger | Properties | Duration | Easing | Reduced motion |
| --- | --- | --- | --- | --- | --- |
| Buttons and section links | Fine-pointer hover | Text, border and background color | 160 ms | ease | Immediate |
| Chart, paired run and tab panel | Data or keyboard action | Immediate state change | 0 ms | — | Same |
