# Red Team report design review

Open [the interactive v3 prototype](v3/index.html) directly in a browser. [Desktop](v3/screenshots/desktop.png) and [mobile](v3/screenshots/mobile.png) screenshots are also available. The preview uses sample results and works offline.

The design replaces the policy comparison panel with an outcome chart and a ranked risk chart. The Plugins and Strategies tabs share one full-width table area. The header keeps the paired-run action and exports. Framework coverage and case results sit beneath the breakdown. The footer calculation disclosure and limitations paragraph are removed from this design.
