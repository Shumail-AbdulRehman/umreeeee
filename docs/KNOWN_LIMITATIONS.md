# Known limitations and deferred work

- Deployment, production hardening, monitoring infrastructure, backups, and live-provider acceptance are excluded from this local implementation. The current verification workspace had no running RabbitMQ service or usable Docker daemon, so actual broker delivery is not signed off; automated tests use a fake publication boundary.
- Enforcement applies to prompts submitted through this application's protected API. It does not intercept traffic sent directly to a provider from another application.
- The red-team catalog is 25 original adversarial templates across five categories plus five controls, with deterministic synthetic markers. Exact-evidence scoring is intentionally narrow: an absent forbidden marker alone is inconclusive, and a score is not proof of general model safety. Provider sampling can change outcomes between runs.
- Semantic prompt-injection/toxicity detectors are imperfect. The small Phase 2 local evaluation and observed latency/timeout limits are documented in `EVALUATION_RESULTS.md`; they must not be described as production accuracy guarantees.
- RabbitMQ delivery is at least once. Mongo leases and fenced writes suppress normal duplicate calls and results, but a crash after an external provider dispatch cannot prove whether the provider completed work. Such an attempt is recorded as unknown outcome/possible cost and is not automatically replayed. Provider-side idempotency would be required for a stronger execution guarantee.
- A test shares its integration's conservative admission pace with ordinary Prompt Studio traffic. The initial single in-flight/6 requests per minute default is an application limit, not the provider's quota. A test can delay workspace calls and produce a 429 with `Retry-After`.
- Content encryption and retention protect stored ordinary and synthetic responses, but administrators remain authorized to see raw synthetic results before expiry. Do not put real personal data or secrets into the attack catalog. A protected output block never reveals the withheld text through Red Team.
- The print action uses the browser print dialog, not a server-side PDF renderer. The catalog does not yet include retrieval/tool-specific attacks, semantic LLM-as-judge grading, automatic policy tuning, or provider-side cost reconciliation for uncertain calls.
