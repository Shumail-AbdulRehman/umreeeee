# Red Team report redesign

Mode: Operate. Administrators should be able to see the overall outcome, identify the riskiest test categories, and get to the results for a particular case.

Scope covers the finished-test report at desktop and mobile widths. The two user-marked areas are removed from the design: the Policy comparison panel and the bottom calculation disclosure and limitations paragraph. The paired-run action stays available in the header when a pair exists. The plugin table uses the whole report width. A Strategies tab replaces the short column alongside it.

Use one compact metric strip, then a shared-height row for the outcome breakdown and highest plugin risks. The sample shows 4 attacks worked, 9 were defended and 1 returned an error. The rate is 4/13 decided and the outcome chart uses all 14 cases. The risk chart uses a fixed 0–10 axis and reports the highest scored plugins first. The full table keeps the evidence behind those charts. Framework results and case results appear below.

Keep Averiq's existing visual identity as a fixed input. Use one demonstrative dataset in the prototype. All interactions are local. Application implementation requires a separate instruction after design review.
